# 🚀 SkillPilot – Interactive Career Roadmap Planner

A modern, interactive web application that helps students and beginners **plan, track, and manage their learning journey** across different career paths with structured roadmaps and smart progress tracking.

---

## 🌟 Features

* 🧭 **Career Roadmap Explorer**

  * Explore multiple career paths (Frontend, Backend, Data Science, etc.)
  * Structured roadmap: Beginner → Intermediate → Advanced

* ✅ **Progress Tracking System**

  * Interactive checklist for each topic
  * Real-time progress percentage calculation
  * Visual progress bar

* 🎯 **Smart Learning Guidance**

  * Highlights next recommended topic
  * Keeps learning structured and goal-oriented

* 📚 **Curated Learning Paths**

  * Organized skills and topics for each career
  * Reduces confusion about what to learn next

* 🎨 **Modern UI/UX**

  * Clean, responsive design
  * Smooth user experience
  * Optimized for performance

* ⚡ **Fast & Lightweight**

  * Built using Vite for high-speed performance

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/ansu06/SkillPilot.git
cd SkillPilot
```

### 2️⃣ Install Dependencies

```bash
npm install
```

### 3️⃣ Run the App

```bash
npm run dev
```

App will run on:

```
http://localhost:5173
```

## 📊 How It Works

1. User selects a career path
2. SkillPilot displays a structured roadmap
3. User marks topics as completed
4. Progress updates instantly in the UI
5. System guides user with next steps
